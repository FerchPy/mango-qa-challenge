# Buggy Cars Rating - QA Automation Suite (HU_2)

Este repositorio contiene la solución de automatización de pruebas E2E desarrollada con **Playwright** para la plataforma *Buggy Cars Rating*, junto con la documentación técnica y pruebas exploratorias de QA.

---

## 🛠️ Requisitos Previos

* **Node.js**: Versión 18 o superior.
  * *Verificar versión:* `node -v`
  * *Instalación en macOS (usando Homebrew):* 
    ```bash
    brew install node
    ```
